# PIN Tools

Одноэкранный каталог экспериментальных веб-тулов PIN с интерактивной
3D-моделью, превью проектов и отдельной мобильной панелью.

## Локальный запуск

Нужен Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

После запуска сайт доступен по адресу, указанному в терминале.

## Проверка перед публикацией

```bash
npm run lint
npm test
```

`npm test` собирает проект и запускает тесты итоговой HTML-разметки.

## GitHub Pages

Публикация запускается автоматически после каждого пуша в ветку `main`.
Готовый сайт: <https://surmsonya.github.io/toolsstudents/>.

Для локальной проверки статической версии:

```bash
npm run build:pages
```

## Структура

- `app/` — страница каталога и стили;
- `public/` — 3D-модель, favicon и изображения превью;
- `tests/` — проверки итоговой разметки;
- `.openai/hosting.json` — конфигурация публикации через Sites.

Проект работает на Next.js, React, vinext и Cloudflare Vite Plugin.
